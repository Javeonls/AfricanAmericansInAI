📝 Case Study: Building Inclusive AI Tools

How we analyzed diversity in AI and improved accessibility with contrast checks.

📊 Data Analysis: Diversity in AI

We analyzed job postings from major tech companies to assess representation of African Americans in AI roles. This involved:

  1. Data Collection: Scraped job postings from LinkedIn, Indeed, and company career pages using Python (Requests, BeautifulSoup).
  2. Data Cleaning: Used Pandas to clean and preprocess the data, handling missing values and normalizing text fields.
  3. Analysis: Calculated metrics such as percentage representation of African Americans in AI roles, gender pay gaps, and trends over time.
  4. Visualization: Created interactive line and bar charts using Chart.js to visualize trends and insights.

The results highlighted significant underrepresentation in leadership roles, prompting discussions on diversity initiatives in AI.

🎨 Accessibility Tool: Contrast Checker

Many websites fail WCAG contrast guidelines, disproportionately affecting users with visual impairments. We built a Python-based tool to automate contrast checks and suggest compliant color palettes.

The tool consists of three main components:

  1. Contrast Calculation: Uses the WCAG contrast ratio formula to evaluate color combinations. The formula calculates relative luminance and contrast ratio between background and text colors.
  2. Python Scripts:
    • check_contrast.py: Evaluates whether a given color combination meets WCAG standards.
    • fix_contrast.py: Suggests improved color palettes for non-compliant combinations.
  3. Machine Learning Integration: A simple logistic regression model was trained to predict contrast compliance based on historical data. This model enhances the tool's accuracy and suggests fixes automatically.

The tool is embedded in the website as an interactive demo, allowing users to test their own color combinations. To use it fully:

  1. Run the Flask backend locally using the command:
    2. cd AfricanAmericansInAI/flask_app && python app.py
  2. Ensure the Flask server is running on http://localhost:5000.
  3. Use the contrast checker in the Accessibility Tool section.

Technical Challenges:

  • Integrating Python scripts with a JavaScript frontend required careful API design to ensure seamless communication.
  • Ensuring the ML model was accurate and efficient for real-time use.
  • Optimizing the Flask backend to handle multiple requests without performance degradation.

💻 Technical Stack and Challenges

This project leverages a diverse set of technologies to achieve its goals:

  • Python: Pandas (data analysis), Scikit-learn (ML model), Flask (backend), and custom scripts for contrast checks.
  • JavaScript: Chart.js (data visualization), Plotly.js (interactive charts), and vanilla JS for frontend logic.
  • Web Development: HTML5, CSS3, and Bootstrap for responsive design.
  • Accessibility: WCAG contrast guidelines, automated checks, and user-friendly suggestions.
  • Backend: Flask API for handling contrast checks and suggestions.

Challenges Faced:

  • Data Scraping: Handling dynamic content and avoiding detection by anti-scraping measures.
  • ML Model Training: Ensuring the model was accurate and efficient for real-time use without overfitting.
  • Integration: Seamlessly connecting Python scripts with JavaScript frontend via Flask API.
  • Performance: Optimizing the Flask backend to handle multiple requests efficiently.
